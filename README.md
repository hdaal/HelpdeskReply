# Helpdesk Reply

Extensão para Chrome que ajuda equipes de help desk e atendimento a organizar respostas prontas em abas personalizadas e inseri-las rapidamente em campos de texto da página ativa.

## Recursos

- Organização das respostas em abas;
- Criação, edição, exclusão e renomeação de abas;
- Pesquisa rápida entre as respostas;
- Cópia ou inserção da resposta escolhida;
- Barra lateral integrada ao Chrome;
- Exportação e restauração da biblioteca em JSON;
- Armazenamento local e sincronização pelo Chrome, quando disponível.

## Instalação para testes

1. Baixe ou clone este repositório.
2. Abra `chrome://extensions` no Chrome.
3. Ative o **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta deste projeto.

## Privacidade

Consulte a [Política de Privacidade](PRIVACY.md). A extensão não envia respostas, conteúdo das páginas ou dados de uso para servidores próprios ou terceiros.

## Publicação

Este projeto também é distribuído pela Chrome Web Store. A versão publicada pode conter ajustes de empacotamento específicos da loja.
