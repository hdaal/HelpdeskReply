# Privacidade do Chrome Reply

O Chrome Reply não envia dados para servidores próprios ou de terceiros. As respostas prontas são armazenadas no perfil local do Chrome e, quando possível, também em `chrome.storage.sync`; caso o Chrome Sync esteja ativado, o próprio Chrome pode sincronizá-las entre dispositivos. A permissão de acesso às páginas é usada somente para inserir a resposta escolhida no campo de texto ativo. O backup JSON só é criado ou lido quando o usuário escolhe Exportar ou Restaurar.
